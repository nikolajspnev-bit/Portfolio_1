# Diandra Pferde – Bilder hier hochladen

In diesen Ordner kommen die Bilder vom Shooting **„Diandra Pferde“**.

## So geht's

1. Oben rechts auf **„Add file“ → „Upload files“** klicken.
2. Die Bilder hineinziehen. Die Dateinamen sind egal.
3. Unten auf den grünen Button **„Commit changes“** klicken und warten, bis der Upload fertig ist.

Hinweise:
- Über den Browser darf **eine Datei höchstens 25 MB** groß sein.
- Pro Upload gehen **höchstens 100 Dateien**. Bei mehr Bildern einfach in mehreren Runden hochladen.

Danach suche ich die besten Bilder aus, verkleinere sie fürs Web und setze sie als eigenes Projekt
ins Portfolio. Die Originale hier räume ich anschließend wieder auf.
