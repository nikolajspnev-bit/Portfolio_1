# Analog-Bilder hier hochladen

In diesen Ordner kommen deine **Analog-Bilder** (Film-Scans) für das Portfolio.

## So geht's

1. Oben rechts auf **„Add file“ → „Upload files“** klicken.
2. Die Bilder hineinziehen – Dateinamen sind egal.
3. Unten auf den grünen Button **„Commit changes“** klicken und warten, bis der Upload fertig ist.

Hinweise:
- Über den Browser darf **eine Datei höchstens 25 MB** groß sein.
- Wenn du magst, schreib mir dazu, welcher **Film** und welche **Kamera** es war (z. B. „Kodak Portra 400, Canon AE-1“) – dann kann ich das bei den Bildern mit angeben.

Danach suche ich die besten Bilder aus, verkleinere sie fürs Web und setze sie ins Portfolio
(`images/portfolio/analog/`). Die Originale hier räume ich anschließend wieder auf.
